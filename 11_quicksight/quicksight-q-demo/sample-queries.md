## Tips for Using Q

1. **Be Natural**: Use conversational language
2. **Be Specific**: Include time periods, regions, or categories when relevant
3. **Use Synonyms**: Try "revenue", "sales", "income" interchangeably
4. **Ask Follow-ups**: Build on previous queries
5. **Experiment**: Try different phrasings of the same question

## Common Patterns

- **"Show me..."** - Good for visualizations
- **"What are..."** - Good for lists and rankings
- **"Compare..."** - Good for comparative analysis
- **"Which..."** - Good for identifying top performers
- **"How much..."** - Good for totals and aggregations

## Troubleshooting Queries

If a query doesn't work, try:
- Simplifying the language
- Using exact column names from your data
- Breaking complex queries into simpler parts
- Checking for typos in product/region names
